Política de Privacidade

Como recolho, uso e protejo os dados que submetes através deste site, em especial pelo formulário de contacto.

Esta política aplica-se aos dados pessoais recolhidos através deste site, nomeadamente pelo formulário de contacto. Ao submeteres esse formulário, aceitas as condições aqui descritas.

Quem é o responsável pelo tratamento dos dados?

Hugo Gonçalves, com o NIF 274269627, é o responsável pelo tratamento dos dados recolhidos neste site. Podes contactar-me através do email work.hugotorres@gmail.com.

Que dados são recolhidos?

Através do formulário de contacto, são recolhidos os seguintes dados, submetidos voluntariamente por ti:

  • Nome
  • Email
  • Tipo de projeto
  • Prazo desejado
  • Orçamento aproximado
  • Mensagem
Para que servem estes dados?

Os dados são usados exclusivamente para responder a pedidos de orçamento e de contacto comercial relacionados com os serviços de design e produção de conteúdo apresentados neste site. Não são usados para nenhuma outra finalidade.

Qual é a base legal para este tratamento?

O tratamento assenta no teu consentimento, dado ao submeteres voluntariamente o formulário de contacto, e em diligências pré-contratuais realizadas a teu pedido, nos termos do artigo 6.º, n.º 1, alíneas a) e b) do Regulamento Geral sobre a Proteção de Dados (RGPD).

Quem tem acesso a estes dados?

Os dados submetidos através do formulário são processados pelo Formspree (formspree.io), um serviço de terceiros usado como intermediário técnico do formulário de contacto, sediado nos Estados Unidos. Não há venda nem partilha destes dados para fins de marketing, e não existem outros destinatários além deste.

Durante quanto tempo os dados são guardados?

Os dados são conservados durante 12 meses após o último contacto, findos os quais são apagados.

Quais são os teus direitos?

Tens, a qualquer momento, direito a:

  • Acesso aos teus dados
  • Retificação de dados incorretos ou incompletos
  • Apagamento dos teus dados
  • Limitação do tratamento
  • Portabilidade dos dados
  • Oposição ao tratamento

Podes exercer qualquer um destes direitos através do email work.hugotorres@gmail.com. Tens também direito a apresentar reclamação junto da Comissão Nacional de Proteção de Dados (CNPD), em www.cnpd.pt.

Este site usa cookies?

Este site não usa cookies de rastreio, cookies de publicidade, nem ferramentas de análise de tráfego que identifiquem visitantes individualmente. Para estatísticas gerais e agregadas de visitas é usado o Cloudflare Web Analytics, uma ferramenta que funciona sem cookies e sem recolher dados pessoais.
